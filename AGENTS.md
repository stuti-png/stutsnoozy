# Portfolio working preferences

- Treat supplied reference videos/screenshots as visual references unless Stuti explicitly asks to embed them. Recreate the requested treatment using the website's existing artwork. Never substitute or embed a watermarked reference clip as a finished website asset.
- Preserve the current artwork, bioscope proportions, video alignment, content and routes when adding motion. Do not change the underlying scene to make an effect easier.
- Before using image/video generation or adding a dependency, check whether the existing assets and simple native CSS/SVG can do the job. Avoid unnecessary generation and credit use.
- Distinguish a measured, verified result from an approximation. Inspect motion in the browser and explain material differences from a reference instead of calling an approximate effect an exact replica.
- Keep navigation typography optically balanced across English and Devanagari. Active-tab underlines must share one baseline.
- Background music was explicitly removed. Do not restore it.
- Verify UI/UX on desktop and mobile after changes; keep simple edits concise and avoid accumulating preview tabs.

- Background animation was explicitly stopped and reverted to the static build. Do not resume animation work or restore animation controls unless Stuti asks again.
